공지도 소개

공기업·공무원 취준생을 위한 기관 정보 서비스

서비스 개요

공지도(govmap.kr)는 전국 344개 공기업·준정부기관·기타공공기관의 위치·연봉·채용 정보를 카카오 지도 위에서 한눈에 비교할 수 있는 취업 정보 서비스입니다.

공공기관 취업을 준비하면서 기관마다 흩어져 있는 정보를 일일이 찾아다녔던 불편함을 해소하기 위해, 직접 데이터를 수집·정제해 운영하고 있습니다.

📌 공지도는 구직자 개인이 직접 만들고 운영하는 독립 서비스입니다. 특정 기관이나 기업과 무관하며, 광고 수익으로 운영됩니다.

주요 기능

  • 지도 기반 위치 탐색 — 본사·전국 지사·사업소 위치를 지도 마커로 확인
  • 연봉 정보 — 초봉·평균연봉·최근 4개년 연봉 추이 (ALIO 공시 기준)
  • 경영평가 등급 — 기획재정부 발표 기준 등급(S·A·B·C·D)과 전년도 비교
  • 채용·시험 정보 — NCS 시험과목, 직렬별 전공과목, 순환근무 여부
  • 필터 검색 — 기관 유형·산업 분야·지역·초봉 조건 조합 필터
  • 정부기관 탭 — 49개 중앙행정기관 및 소속 지방청·사무소 위치 탐색
  • 발령지 반경 탐색 — 내 연고지 기준 반경 내 정부기관 필터링

데이터 출처 및 정확성

공지도의 모든 정보는 아래 공식 출처를 기반으로 수집·정제합니다.

  • 연봉 데이터 — 공공기관 경영정보 공개시스템 (ALIO) 공시자료 기준
  • 기관 주소·지사 정보 — 각 기관 공식 홈페이지 및 오시는길 페이지 직접 확인
  • 채용·시험 정보 — 각 기관 실제 채용공고 원문 기준
  • 경영평가 등급 — 기획재정부 공식 발표 자료 기준
  • 정부기관 정보 — 각 부처 공식 홈페이지 및 정부24 (gov.kr) 기준

데이터는 매년 ALIO 공시 이후 갱신하며, 채용공고 기반 정보(NCS·전공과목 등)는 최신 공고가 확인되는 대로 업데이트합니다. 단, 기관 사정에 따라 일부 정보가 실제와 다를 수 있으므로 중요한 사항은 반드시 해당 기관 공식 채용공고를 직접 확인하시기 바랍니다.

운영 원칙 및 데이터 검증 방법

공지도는 "공개된 1차 출처만 사용, 추정 기재 금지"를 운영 원칙으로 삼습니다. 구체적인 검증 절차는 아래와 같습니다.

  • 연봉 — ALIO 공시 PDF를 직접 내려받아 "신입사원 초임" 및 "1인당 평균 보수액" 행을 확인. 수정공시가 있는 경우 최신 버전으로 반영
  • 본사 주소 — 각 기관 공식 사이트 "오시는길" 페이지 + ALIO 기관정보 두 가지를 교차 대조. 불일치 시 추가 출처로 재검증
  • 지사·사업소 — 기관 조직도·지사 안내 페이지 직접 열람. 일부 기관은 지방청·사업소 페이지를 개별 방문해 주소 확인
  • 채용·시험 정보 — 기관 자체 채용공고 원문(PDF) 또는 공고 본문을 직접 확인. 합격후기·커뮤니티 글 등 2차 출처는 사용하지 않음
  • 경영평가 등급 — 기획재정부 공식 보도자료 기준으로 입력

확인이 불가능한 정보는 기재하지 않으며, 오류 제보가 들어오면 출처를 재확인 후 수정합니다.

운영자 정보

공지도는 공기업·공공기관 취업을 직접 준비하면서 기관 정보를 하나씩 찾아다녔던 경험에서 출발했습니다. 기관별로 흩어진 연봉·위치·시험 정보를 한 곳에서 비교할 수 있는 서비스가 없다는 걸 느끼고, 직접 데이터를 수집해 만들기 시작했습니다.

현재 344개 공공기관 + 49개 정부기관의 데이터를 개인이 직접 수집·검증하고 있으며, ALIO 공시 주기에 맞춰 연봉을 갱신하고, 채용공고가 나올 때마다 시험과목·모집분야를 업데이트합니다. 사용자 오류 신고도 적극 반영합니다.

면책 사항

공지도에서 제공하는 정보는 공개 자료를 기반으로 하며, 채용 결과나 연봉을 보장하지 않습니다. 실제 채용 조건은 각 기관의 공고를 반드시 직접 확인하시기 바랍니다. 정보 오류에 대한 법적 책임은 지지 않으나, 발견 즉시 수정할 수 있도록 적극 신고해 주세요.
